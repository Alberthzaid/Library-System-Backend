Holaa... esta una pequeña API Rest hecha con flask para postularme como tutor de Python Pro.

La implementacion es una API de Libreria que crea un CRUD de libros y librerias.

Conexion a una base de datos PostgreSQL usando Supabase.

La API se desplego en render y esta completamente funcional

Endpoints 

https://library-system-backend-dc79.onrender.com

https://library-system-backend-dc79.onrender.com/get/Book/<id>

agregar un nuevo libro

https://library-system-backend-dc79.onrender.com/add/Book
